祭

はじめに・言葉の意味

お客さんは自分のスマホから注文します。お店は注文帳で注文を受けて調理し、できあがったら大画面に番号を出して呼び出します。お店の前で直接注文する人はレジで受け付けます。材料などを買ったときのレシートは、スタッフが写真で送り、店長が確かめて収支に入れます。

使う画面と、だれが使うか

画面何をする画面か使う人
管理画面 店舗の設定、スタッフ用 PIN、メニュー、注文の検索と修正、売上、収支、レシートの確定 店長（運営から伝えられたメールアドレスとパスワードでログイン）
注文帳・レジ・レシート 注文を受けて進める、対面の注文を会計する、売り切れを設定する、レシートを撮って送る 当日のスタッフ全員と店長（店の URL を開き、PIN を入れる）
大画面 できあがった番号をお客さんに見せる（モニターに映しっぱなし） お客さん向け（スタッフが映す。ログインなし）

店の URL・PIN・店長のアカウントは、このマニュアルには書きません。スタッフは店長から、店長は運営から伝えられます。

用意するもの

  • 注文帳・レジ用のタブレットかスマホ（横向きのタブレットがいちばん見やすい）
  • 大画面用のモニター（ノートパソコンやタブレットをつないで映す）
  • 充電器・延長コード、つながる Wi-Fi か携帯回線
  • レシートを撮るスマホ（スタッフのスマホでかまいません）
飲食以外の店（展示・物販など）の場合

画面の言葉が少し違います。このマニュアルは飲食の店の言葉で書いています。

例: 受付 → 調理中 → お渡し待ち（飲食）は、待ち → 呼び出し中（飲食以外）。「調理をはじめる」「できあがり」「お渡し済み」は、「呼び出す」「完了」。

言葉の意味

整理番号（お呼び出し番号）
注文ごとの番号です（例: A-12）。お客さんはこの番号で呼ばれ、受け取るときに見せます。
頭文字
整理番号の最初の文字（A-12 の「A」）。店ごとに決まっていて、運営が決めます。
受付・調理中・お渡し待ち・お渡し済み
注文の進み具合です。注文帳のボタンで、左から右へ進めます。
未受取・取り消し
未受取は、呼び出したのに取りに来なかったので取り置きをやめた注文。取り消しは、注文をなかったことにすることです。元に戻せるのは店長だけです。
売り切れ
お客さんが注文できなくなります。商品ごとにも、選択肢（トッピングなど）ごとにも設定できます。
PIN
注文帳・レジに入るための、6〜12桁の数字です。店長が決めて、スタッフに伝えます。
開催（今回の開催）
学園祭そのもの（例: 第1回 サンプル祭）。売上・注文・収支は開催ごとに分かれています。
開催回（本番・練習）
開催の中の1日1日（例: 練習、本番1日目、本番2日目）。本番の開催回をすべて合わせたものが、学校に出す収支報告になります。練習の開催回の収支は、収支報告に入りません。
収支
収入（売上・補助金など）と支出（食材・消耗品など）。売上は注文から自動で数えます。
レシート番号
登録したレシートの番号です（例: R-0012）。学校に出す書類の支出明細と、レシートの画像のファイル名に使います。
科目
収入・支出の種類です（例: 食材、消耗品、備品、補助金）。

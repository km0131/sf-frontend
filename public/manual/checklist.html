印刷して使えます。それぞれの項目のくわしいやり方は、かっこの中のページにあります。

店長用

前日まで

  • 管理画面にログインできる・パスワードを変えた（前日までの準備）
  • 店舗設定（店名・添え書き・取り置き時間・数量の上限・メール）を確かめた
  • スタッフ用 PIN を設定した
  • メニュー（カテゴリ・値段・選択肢・写真）を登録し、お客さんの画面で確かめた
  • 注文帳・レジ・大画面を開いて、テスト注文で一通り試した（テスト注文は取り消した）
  • 目標利益を決めた（0 円なら黒字が目標）（損益と見込み）
  • 補助金など、レシートのない収入・支出を収支に入れた（収支の画面）

当日 開店前

  • スタッフに注文帳・レジの URL と PIN、大画面の URL を伝えた
  • レシートを撮る係を決め、開催回の選び方（本番の日）を伝えた（レシートの送り方）
  • 機材の配置・電源・通信を確かめた
  • スタッフのチェックリスト（開店前）が終わった

閉店後（毎日）

  • 注文帳に残っている注文がないか確かめた
  • 現金照合を記録した（収支の画面）
  • 余った食材の金額を「廃棄」に記録した（収支の画面）
  • その日のレシートをすべて確定した・照合チェックを見た（レシートの検索と照合チェック）
  • 売上を確かめた（売上の画面）
  • 次の日に向けて、売り切れを戻した

学園祭のあと

  • 確定していないレシートが 0 件になった
  • レシートと二重になっている手入力の支出がない
  • Excel とレシート画像（ZIP）をダウンロードし、中身を確かめて提出した（学校に出す書類）

スタッフ用

開店前

  • 注文帳・レジに PIN でログインした
  • 右上が「● 接続中」になっている
  • 画面をタップして「音：入」になった・端末の音量を上げた
  • 大画面をモニターに全画面で映し、「音：入」にした
  • 最初から無い商品を売り切れにした

営業中

  • 「できあがり」を押したら、大画面に番号が出ている
  • お渡しのときは、整理番号を確かめてからお代金を受け取る
  • 期限切れのカードがないか、ときどき見る
  • 買い出しのレシートは、全体が入るように真上から撮って送る
  • 困ったら店長に連絡する

閉店時

  • お渡し待ち・受付が残っていない
  • その日のレシートを送った
  • 注文帳・レジをログアウトした・大画面を閉じた
  • 機材を片付けて充電した

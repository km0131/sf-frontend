売上の画面

メニューの 売上 を開きます。上の1行の条件（開催回・数える日・時間帯の区切り・時間帯を見る日）が、その下のすべての表とグラフに効きます。

いつも見るところ

  • 売上・注文・客単価・販売個数: 支払い済みの注文だけを数えます（取り消し・受け取りなしは数えません）。売上は値引きを引いたあとの金額（実売上）です。
  • 日別の売上・時間帯別の注文数・商品別: どの日・どの時間に、何が売れたか。選択肢（麺・トッピングなど）の選ばれ方も見られます。
  • 注文の経路: レジと Web 注文の割合。
  • 開催回の比較: これまでの開催との比較。
  • CSV を書き出す: 右上のボタンで、注文の明細を CSV（Excel で開けるファイル）で保存できます。値引きの列（明細の値引き・その内容・値引き後の小計・注文全体の値引き など）は、いちばん右に並びます。「単価」「小計」は定価、「注文合計」はお支払いの金額です。

数える日を切り替える

  • すべての日（練習も）: 開催のすべての日の注文を数えます（最初はこちら）。
  • 本番の日だけ（収支・Excel と同じ）: 本番の開催回の日の注文だけを数えます。収支の画面や学校に出す書類の売上と同じ数字になります。

提供時間（待ち時間）

  • 平均・ふつう（中央値）・遅いほうの1割・いちばん長い: 注文からできあがりまでの時間です。「遅いほうの1割」は、これより長く待った注文が1割ある、という時間です。
  • 調理時間の平均: 調理中からできあがりまで。
  • 受け渡しまで: 注文から、お渡し済み（完了）を押すまでの時間です。お客さんが受け取るまでにかかった時間の目安になります。

ロス（取り消し・受け取りなし・廃棄）

  • 取り消し・受け取りなし: 件数と金額。
  • 廃棄（余った食材）: 収支の画面で開催回ごとに入れた金額の合計です（入れ方は → 収支の画面の「廃棄」）。買ったときの値段で、収支には足しません（支出はもう入っているため）。

売り切れの記録

レジや商品の画面で売り切れにした時刻と、販売に戻した時刻が自動で残ります。戻していなければ「売り切れのまま」と出ます。次の日に作る量を決めるときの参考にしてください。

ここに出るのは手動の売り切れ（売り切れのボタン）だけです。限定の品が残り 0 になった自動の売り切れは、下の「限定商品」の表で見ます。

値引き

値引きがあった期間は、いちばん上の数字の下に、もう1段の数字が出ます。

  • 定価ベースの売上: 値引きがなかった場合の売上。
  • 値引き総額: 商品ごとの値引きと注文全体の値引きの合計。
  • 実売上: 定価ベースの売上 − 値引き総額。お客さんから受け取った金額で、収支・学校に出す書類の売上と同じ考え方です。

下の「値引き」の表には、値引きごとの件数と金額が出ます（商品ごとの値引きは品の数、注文全体の値引きは注文の数）。金額を自由に入れた値引きは「自由入力」として1行にまとめます。自動で適用した値引き（閉店前のセールなど）も、その値引きの名前で出ます。

「商品別」の表の売上は、商品ごとの値引きを引いた金額で、「値引き」の列に引いた額が出ます（注文全体の値引きは、商品には割り振りません）。

限定商品

限定の品がある店だけ出ます。営業日ごとに次の数が並びます。

  • 限定数: 販売済み＋残り。レジで「追加で焼けた」「失敗・廃棄」と直すと、その分だけ増えたり減ったりします。
  • 販売数: 取り消しを除いた注文の数（まだ受け取っていない Web 注文も入ります）。
  • 残り: 売らずに残った数。
  • 失敗・廃棄: 限定数を直すときに「失敗・廃棄」を選んで減らした数の合計。

次の日の限定数を決めるときの参考にしてください。直した記録（いつ・だれが・なぜ）は、商品の画面の「限定数の修正の記録」で見られます。
